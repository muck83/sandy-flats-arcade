Worked example: case file 0

Question: Find the slope of the line through (1, 5) and (3, 1).

Student work:  m = (3 − 1) ÷ (1 − 5) = 2 ÷ (−4) = −½

Detective stepWhat I find
Read the questionSlope = change in y ÷ change in x.
Find the first wrong stepThe first line: the x-values (3 − 1) are on top.
Name the mistakeRise and run are swapped (the fraction is upside down).
Write the fixm = (1 − 5) ÷ (3 − 1) = −4 ÷ 2 = −2
Why someone might do itBoth parts use subtraction, so it is easy to mix up which goes on top.
