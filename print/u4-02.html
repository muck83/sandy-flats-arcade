One, None or Infinitely Many
Name Class Date
Mini-lesson · 5 min I can solve an equation and tell if it has one, no, or infinitely many solutions.
Fill in the notes

1. To solve, do the same to both sides, so the equation stays .

2. If you end with x = a number, there is solution.

3. If the x’s disappear and you get a true statement, like 6 = 6, there are solutions. number works.

4. If the x’s disappear and you get a false statement, like 1 = −3, there is solution. No number works.
